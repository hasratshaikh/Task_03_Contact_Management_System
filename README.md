
# Contact Management System

A simple and user-friendly Contact Management System developed using Python. This application allows users to store, view, search, update, and delete contact information through a command-line interface.

## Features

- Add new contacts
- View all saved contacts
- Search contacts by name or phone number
- Update existing contact details
- Delete contacts with confirmation
- Validate email addresses
- Prevent duplicate phone numbers
- Store contact information in a JSON file
- Handle empty contact lists and invalid menu choices

## Technologies Used

- Python
- JSON
- Regular Expressions
- pathlib

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Task_03_Contact_Management_System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Task_03_Contact_Management_System
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## How to Use

After running the application, select an option from the menu:

| Option | Function |
|--------|----------|
| 1 | Add Contact |
| 2 | View All Contacts |
| 3 | Search Contact |
| 4 | Update Contact |
| 5 | Delete Contact |
| 6 | Exit |

Contact information is stored locally in the `contacts.json` file.
